# Habbo Headless — pacote para servidor

1. Extraia a pasta inteira em um local privado do computador-servidor.
2. Abra `Habbo Headless.exe` na raiz da pasta.
3. O painel abrirá em `http://127.0.0.1:3000`.
4. Os logins com e-mail e senha já estarão salvos. Para contas Steam, mantenha o Steam autenticado nesse computador antes de conectar.

## Segurança

Este pacote contém credenciais portáteis cifradas para permitir o uso no novo computador. Não envie, publique ou deixe o ZIP acessível a terceiros. Para transferir, use um meio privado e apague a cópia intermediária depois de confirmar que o servidor está funcionando.
